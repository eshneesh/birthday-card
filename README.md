# Birthday card

Интерактивная страница-открытка ко дню рождения: editorial-коллаж, фотографии, анимированные конверты и письма с поздравлениями.

## Как заменить тексты

В конце `index.html` находится массив `letters`. Для каждого письма можно заменить поля `title`, `body` и `signature`.

Фрагменты «С / днём / рождения!» находятся в разметке элементов `.mail-word`. Позже их можно заменить подготовленными изображениями рукописной фразы.

## Как заменить фотографии

Фотокольцо находится в блоке `.photo-orbit`. В нём подготовлено десять кадров `.orbit-frame`: достаточно заменить пути `src` на новые общие фотографии, а сборка кольца, вращение и scroll-анимация сохранятся автоматически.

## Локальный просмотр

```bash
python3 -m http.server 4173
```

После запуска откройте `http://127.0.0.1:4173`.
