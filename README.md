# Birthday card

Интерактивная страница-открытка ко дню рождения: editorial-верстка, фотографии, анимированные конверты и письма с поздравлениями.

## Как заменить тексты

В конце `index.html` находится массив `letters`. Для каждого из четырёх писем можно заменить поля `title`, `body` и `signature`. Третье письмо пока оставлено с текстом-заглушкой.

На первых трёх конвертах находится отдельный слот `.mail-word` для цельной рукописной фразы. Используются файлы `handwriting-01.png`, `handwriting-02.png` и `handwriting-03.png` из `assets/birthday-card/`; четвёртый элемент оформлен как маленькая записка.

## Как заменить фотографии

Фотокольцо находится в блоке `.photo-orbit`. В нём семь уникальных кадров `.orbit-frame` без повторов. Лес, дети и «деды» подключены как вертикальные элементы `.orbit-frame--portrait`; все файлы лежат в `assets/birthday-card/collages/`.

Шрифт Gogol подключён из `assets/birthday-card/fonts/gogol-regular.otf` и используется для всех рукописных и курсивных элементов интерфейса.

## Локальный просмотр

```bash
python3 -m http.server 4173
```

После запуска откройте `http://127.0.0.1:4173`.
